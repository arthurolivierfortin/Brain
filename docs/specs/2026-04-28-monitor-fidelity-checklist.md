# Checklist — Brain Monitor Fidelity Pass

**Linked spec:** [2026-04-28-monitor-fidelity-design.md](2026-04-28-monitor-fidelity-design.md)

**Budget:** 1.5 days. **Roadmap phase:** R:phase-2b. **Single PR.** **Single file modified:** `backend/src/brain/static/brain.html`. **~600–800 LOC** additions/modifications.

**Commit emoji convention** (per CLAUDE.md):
- `🧠 Feature` for net-new components (`<HashRouter>`, `<MemoryInspector>`, `<HookReplay>`, `<AgentProfile>`, `<MemoryTypeCooccurrence>`, `<LayerRing>`, animation hooks, `useL2Recents`).
- `🧬 Refactor` when an existing component changes its shape (`<App>` lifts agent filter + wraps in router; `<Header>` restructures into left/right halves; `<BrainGraph>` integrates ring + animation passes; `<MatrixView>` becomes `<AgentTypeMatrix>` and is demoted to a sub-view; `<Footer>` gains tail indicator + empty state; `<TweaksPanel>` adds `animations` toggle; `TWEAK_DEFAULTS` extended).
- `📓 Docs` only if a README/spec is touched (this checklist + spec are part of this PR but they ship under their own commit).

**HTML/JSX verification policy** (Phase 2b-fidelity, inherits Phase 1/2/3 precedent): every [SPEC-N] in this checklist is HTML/JSX-only inside the single `brain.html` file. Verification is **manual eyeballing** during dogfood at `http://localhost:8621/monitor`. Each [SPEC-N] documents its manual verification anchor inline. **ZERO new pytest tests are added** (resolves Q15). The Phase 1/2/3 + L2-B baseline of 220 backend tests acts as the automated no-regression coverage; both `[GATE-1]` ruff and `[GATE-2]` pytest must remain green. Browser-level testing arrives in Phase 4 (Next.js + Playwright).

**No-regression invariant.** Phase 1 + Phase 2 + Phase 3 + L2-B surfaces MUST continue to work after the fidelity pass. Concretely, after the merge, opening `/monitor` MUST exhibit:

- Header: cluster cores top-8 dynamic from `/stats.types`; `mem` and `swap` Bars; uptime; activity sparkline; status dot reflecting `lastError`. (Phase 1)
- Tweaks panel: `polling on`, `speed`, `accent`, plus the new `animations` toggle (Phase 1 + this PR's [SPEC-2]); localStorage persists across reload (Phase 3 `useTweaks`).
- Graph tab: force-directed simulation; click-to-focus; drag-to-pin; pan + zoom; refresh button; activation halos. (Phase 2)
- Matrix tab: heatmap renders. (Phase 3, restructured by [SPEC-9])
- Console tab: latest 100 events; auto-scroll + follow pill. (Phase 3, restructured by [SPEC-10])
- Footer: filter input + matches badge; events list with type-color badges + relative timestamps. (Phase 1 + Phase 3)
- Thought stream: events list with focus filtering when a node is focused. (Phase 2)
- Keyboard shortcuts `g`, `m`, `c`, `space`, `r`, `t`, `Escape`, `/` continue to work; the input-guard prevents shortcut firing while typing in inputs. (Phase 3)
- L2-B enriched events (`metadata.memory_ids`, `metadata.cosine_scores`, `metadata.tokens_per_layer`, `metadata.topic_query_used`) continue to flow through `/events`. (L2-A + L2-B)

The fidelity pass only **adds** components and **modifies** the surfaces enumerated below. Phase 1/2/3 + L2-B [SPEC-N] items are append-only and are **not** edited in this PR.
